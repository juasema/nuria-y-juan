# Web de boda · Nuria & Juan

Primera versión estática de la web. Está preparada para publicarse gratis en GitHub Pages.

## Contenido
- `index.html`: secciones y textos de la web.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: menú móvil y configuración del enlace RSVP.
- `assets/ramita.svg`: ilustración floral vectorial.

## Antes de publicarla
1. Sustituir los bloques de fotografía de `index.html` por vuestras imágenes.
2. Completar horarios, dress code, transporte y fecha límite de confirmación.
3. Crear el formulario en Tally y pegar su enlace público en `TALLY_URL` dentro de `script.js`.
4. Revisar el formulario y su aviso de privacidad antes de compartirlo.

## Publicar gratis con GitHub Pages
1. Crear/iniciar sesión en https://github.com/
2. Crear un repositorio público llamado `nuria-y-juan`.
3. Subir el contenido de esta carpeta (no la carpeta ZIP).
4. Ir a Settings → Pages.
5. En Build and deployment elegir `Deploy from a branch`.
6. Elegir `main` y `/ (root)`, guardar.
7. GitHub publicará la web en `https://TU-USUARIO.github.io/nuria-y-juan/`.

La dirección exacta dependerá de vuestro nombre de usuario de GitHub.

## RSVP
El botón de confirmación no almacena respuestas todavía. Es intencionado: no conviene recoger datos personales o posibles datos de salud mediante un formulario sin haber configurado correctamente el proveedor, los permisos y la información de privacidad. El siguiente paso es crear el formulario de Tally y conectar su URL.
